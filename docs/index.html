🇮🇹 The Partner

Italia Online (IOL) is Italy’s largest digital services provider for small and medium businesses — 130,000 paying SMB customers, 700+ field sales agents, and 40,000 Duda websites managed across Italy. IOL sells MARIO, an AI Voice Receptionist that answers phone calls in Italian, and InRete AI, a web chat assistant.

💡 Why This Integration

MARIO answers calls for Italian businesses — but cannot complete a booking because there is no integration with any scheduling system. IOL has 40,000 Duda websites and Duda Bookings is a new feature that Duda is launching. This integration enables IOL to offer a MARIO + Booking package to all 40,000 businesses — a new revenue stream at 1,399 to 2,500 euros per year per business.

I wrote the mission brief, defined 4 MCP booking tools, managed the cross-team delivery with PURI and AI Experience teams, and navigated a mid-build API migration when Duda replaced their booking API with a new AI-agent-specific Proxy API.

Complete

Engineering built the Duda booking connector: scaffold, connection lifecycle, Basic Auth with site scoping, disconnect cleanup. Each business connects by entering Duda API credentials — system validates immediately with a test call.

AI Capability Registration

Complete

Registered ‘Manage bookings with Duda’ capability in the AI Capabilities editor. 4 MCP booking tools: list appointment types, check availability, create appointment, look up booking. Works on both Voice AI (phone calls) and Chat AI (web chat). Same pattern as Octotable.

◈ T7 and T8 — Done

End-to-End Demo Validation

Complete

Validated the full flow: customer calls, MARIO asks what service they want, checks available times via Duda API, books the appointment, customer gets confirmation. Tested in Italian. Tested voice and chat channels. Timezone handling validated.

◈ 17 of 21 tickets completed

Duda API Migration

In Progress

Duda replaced their booking API mid-build with a new AI-agent-specific Proxy API. Token-based auth replaces username/password. Appointment lookup removed (privacy reasons — replaced with email link). Added booking idempotency keys to prevent double-booking on retries. ~1 week engineering estimate.

◈ Spike XPAN-58 — In Progress

Production Rollout

Blocked

Phase 1 built and running in demo. Production access not yet open on Duda’s side. IOL pilot business ready once Duda opens their API.

Integration Details

Click any card to expand technical and process details for each integration component.

📅 Duda Booking Tools (MCP)

▼
  • List appointment types — what services the business offers
  • Check availability — free time slots for a specific service and date
  • Create appointment — book with customer name, phone, email, notes
  • Look up booking — find existing appointments (removed in new API, replaced with email link)
  • Idempotency keys prevent double-booking on timeout retries
  • Timezone-aware scheduling — business timezone set on connection

🤖 AI Capability Architecture

▼
  • “Manage bookings with Duda” capability card in Business App
  • Same pattern as Octotable AI Reservation capability
  • Works with both Voice AI employees (phone calls) and Chat AI employees (web chat)
  • Capability scoped to ASSISTANT_TYPE with access control
  • Secure per-account credential storage — one set per business
  • Setup target: under 10 minutes per business

⚡ Stripe Connect and BYOPG

▼
  • Stripe Connect Standard account model — EUR primary currency
  • Automated product activation post-payment (under 30 seconds)
  • Bring Your Own Payment Gateway — zero-touch partner onboarding
  • GDPR-compliant data processing — PCI DSS Level 1 via Stripe
  • Italian VAT compliance built into billing
  • Daily activation ramp: ~48 AI subscriptions per weekday

🌐 Localisation and Compliance
