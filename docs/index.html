💡 Why This Integration

The AI Voice Receptionist answers calls for businesses — but cannot complete a booking because there is no integration with any scheduling system. The partner has 40,000 websites on the booking platform, and this integration enables a new Voice Receptionist + Booking package for all 40,000 businesses — a new revenue stream at 1,399 to 2,500 euros per year per business.

I wrote the mission brief, defined 4 MCP booking tools, managed cross-team delivery, and navigated a mid-build API migration when the booking platform replaced their API with a new AI-agent-specific Proxy API.

Integration Journey

Timeline

From discovery through production — the milestones that brought the AI Receptionist and the booking platform together.

Discovery and Spike

Complete

Mapped the partner’s website landscape: 40,000 sites, zero businesses with bookings today. Analysed the booking platform’s API documentation and sandbox. Identified an existing AI booking capability as the reference pattern.

◈ 21 tickets scoped

Mission Brief

Complete

Wrote the mission brief defining the full integration scope: 4 booking tools, AI capability card for Voice and Chat, credential validation flow, edge cases (11 scenarios), outcome targets (50+ connections in 60 days, 75%+ booking success rate), and phasing (Part 1: core booking, Part 2: cancel, reschedule, payments).

◈ 6 supporters listed for review

Connector Build

Complete

Engineering built the booking connector: scaffold, connection lifecycle, Basic Auth with site scoping, disconnect cleanup. Each business connects by entering API credentials — system validates immediately with a test call.

◈ Core tasks T0 through T6 — all Done

AI Capability Registration

Complete

Registered the booking capability in the AI Capabilities editor. 4 MCP booking tools: list appointment types, check availability, create appointment, look up booking. Works on both Voice AI (phone calls) and Chat AI (web chat).

◈ Capability tasks — Done

End-to-End Demo Validation

Complete

Validated the full flow: customer calls, the AI Receptionist asks what service they want, checks available times via the booking API, books the appointment, customer gets confirmation. Tested in the partner’s native language. Tested voice and chat channels. Timezone handling validated.

◈ 17 of 21 tickets completed

API Migration

In Progress

The booking platform replaced their API mid-build with a new AI-agent-specific Proxy API. Token-based auth replaces username/password. Appointment lookup removed for privacy. Added booking idempotency keys to prevent double-booking on retries. ~1 week engineering estimate.

◈ Migration spike — In Progress

Production Rollout

Blocked

Phase 1 built and running in demo. Production access not yet open on the booking platform’s side. Partner pilot business ready.

◈ Blocked on external API access

Deep Dive

Integration Details

Click any card to expand technical and process details for each integration component.

📅 Booking Tools (MCP)

▼
  • List appointment types — what services the business offers
  • Check availability — free time slots for a specific service and date
  • Create appointment — book with customer name, phone, email, notes
  • Look up booking — find existing appointments (removed in new API, replaced with email link)
  • Idempotency keys prevent double-booking on timeout retries
  • Timezone-aware scheduling — business timezone set on connection

🤖 AI Capability Architecture

▼
  • Booking capability card registered in the business application
  • Same pattern as existing reference pattern for AI reservation capability
  • Works with both Voice AI employees (phone calls) and Chat AI employees (web chat)
  • Capability scoped to ASSISTANT_TYPE with access control
  • Secure per-account credential storage — one set per business
  • Setup target: under 10 minutes per business

⚡ Payment Integration

▼
  • Payment gateway Standard account model — EUR primary currency
  • Automated product activation post-payment (under 30 seconds)
  • Bring your own payment gateway — zero-touch partner onboarding
  • GDPR-compliant data processing — PCI DSS Level 1 compliance
  • European VAT compliance built into billing
  • Daily activation ramp: ~48 AI subscriptions per weekday

🌐 Localisation and Compliance

▼
  • AI Receptionist configured for native language — all confirmations localised
  • 1,000+ CRM strings translated for local interface
  • GDPR consent capture for AI voice and chat
  • AI Chat Assistant packages: 1,399 to 2,500 euros per year
  • Semicolon-CSV import support (European Excel format)
  • Cross-border coordination: Indian, Canadian, and European stakeholders
