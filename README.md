## The Story

A European enterprise partner has 40,000 websites and sells an AI Voice Receptionist to local businesses. The AI answers calls — but cannot book appointments because there is no integration with the scheduling system.

**What I did:**
- Wrote the mission brief (11 edge cases, 5 outcome targets, 6 supporters)
- Defined 4 MCP booking tools (list services, check availability, create appointment, look up booking)
- Managed cross-team delivery across integration team, AI platform team, and external contacts in 3 time zones
- Navigated a mid-build API migration when the booking platform replaced their API
- Shipped 17 of 21 tickets — Phase 1 running in demo

## Tech

Pure HTML/CSS/JS — no frameworks, no build step, no dependencies (except Google Fonts). Self-contained in a single `docs/index.html` file. Deployed via GitHub Pages.

**Interactive features:**
- Chat widget with typed message animation + suggestion chips
- Clickable PM workflow with expanding detail panels
- Tabbed stakeholder views with fade transitions
- Scroll-reveal animations via IntersectionObserver
- Expandable Deep Dive cards
- Responsive across mobile, tablet, and desktop
